Permission prompt Never shown — already granted

How it works

  • No prompt, ever. When a site asks for your position, the app answers yes in code. The permission dialog is never drawn.
  • Your real location is never read. No GPS, no Wi-Fi scan. The coordinates are a constant compiled into the app.
  • Nothing contradicts. Timezone, language and number formatting all match Mumbai, so prices and dates come out ₹12,34,567.89 and clocks run on IST.
  • Sites that pre-check. Maps, Zomato and Swiggy query the permission first, get granted, and skip their own "Enable location" button entirely.

Deliberately not a browser

Has
  • One address bar
  • Back, forward, refresh
  • Automatic history with search
  • Light and dark mode
Does not have
  • Tabs or bookmarks
  • Downloads or extensions
  • Profiles or multiple windows
  • Browser settings

Moving it somewhere else

Edit one file — src/config/location.ts — and rebuild. That is the only way to change the reported location, which is the point: it can never be switched off by accident, and nobody has to remember to turn it on.

Installing

The builds are unsigned, so the first launch needs one extra click.

macOS — right-click the app and choose Open, then confirm.
Windows — on the SmartScreen prompt choose More info → Run anyway.

One honest limit: this changes what sites read from the browser, not your IP address. A site that geolocates purely by IP still sees your real connection.
